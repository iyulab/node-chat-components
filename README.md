# @iyulab/chat-components

대화형 LLM 채팅 인터페이스를 구현하기 위해 필요한 컴포넌트들을 제공합니다.
현재 개발중으로, 일부 컴포넌트는 미완성 상태입니다.

## 📦 설치

```bash
npm install @iyulab/chat-components
```

## 🚀 사용법

```javascript
// 모든 컴포넌트를 사용하려면 다음과 같이 import 합니다.
import '@iyulab/chat-components';

// 컴포넌트에 필요한 스타일을 import 합니다.
import '@iyulab/chat-components/styles/light.css';
import '@iyulab/chat-components/styles/dark.css';
```

## 📚 컴포넌트

### 메시지 관련 컴포넌트
- `<uc-message>`: 메시지 컴포넌트
- `<uc-text-block>`: 텍스트 컨텐츠 표시
- `<uc-markdown-block>`: 마크다운 컨텐츠 표시
- `<uc-thinking-block>`: 추론 컨텐츠 표시
- `<uc-tool-block>`: 도구 컨텐츠 표시
- `<uc-code-block>`: 코드 컨텐츠 표시

### 기타 컴포넌트
- `<uc-alert>`: 알림 컴포넌트
- `<uc-button>`: 버튼 컴포넌트
