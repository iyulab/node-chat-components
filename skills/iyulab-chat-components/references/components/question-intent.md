# u-question-intent

```ts
import '@iyulab/chat-components/dist/components/intents/UQuestionIntent.js';
```

**Tag:** `u-question-intent`

Renders a question with clickable choice buttons generated by the LLM. Fires a `choice` event when the user selects an option.

`u-marked-block` strips `intent-json` code blocks from the rendered output, so you must parse them manually using `IntentPromptBuilder` and create this component yourself.

```html
<!-- Basic usage -->
<u-question-intent
  question="What topic are you interested in?"
  .choices=${["Artificial Intelligence", "Blockchain", "Cloud Computing"]}
></u-question-intent>

<!-- Choices only, no question text -->
<u-question-intent
  .choices=${["Yes, continue", "No, stop"]}
></u-question-intent>
```

```ts
const intent = document.querySelector('u-question-intent');

intent.addEventListener('choice', (e) => {
  const { value } = e.detail; // selected choice text
  console.log('Selected:', value);

  // Auto-fill and submit the prompt
  prompt.value = value;
  prompt.submit();
});
```

Parsing from an LLM response with `IntentPromptBuilder`:

```ts
import { IntentPromptBuilder, PresetIntent } from '@iyulab/chat-components';

// Setup
IntentPromptBuilder.instance.use(PresetIntent.Questions);

// Parse LLM response
const [cleanText, intents] = IntentPromptBuilder.instance.parse(llmResponse);

for (const intent of intents) {
  if (intent.type === 'question') {
    const el = document.createElement('u-question-intent');
    el.question = intent.properties?.question;
    el.choices = intent.properties?.choices ?? [];
    messageContainer.appendChild(el);
  }
}

markedBlock.value = cleanText;
```

---

## Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `question` | `string` | `undefined` | Question text shown above choices. Hidden if not set |
| `choices` | `string[]` | `[]` | Clickable choices (1–5 recommended). Renders nothing if empty |

## Events

| Event | Detail | Description |
|-------|--------|-------------|
| `choice` | `{ value: string }` | Fired when a choice button is clicked |
